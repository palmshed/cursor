# Cursor

Cross-platform AI coding agent. C++20, 16 services, 8 AI providers, CI/CD across 3 platforms.

## Install

Homebrew:
```bash
brew install cursor
```

npm:
```bash
npm i -g @bniladridas/cursor
```

## Build from Source

```bash
cmake -S . -B build && cmake --build build
./build/cursor-tests
```

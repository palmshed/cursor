# Cursor

Cursor is a terminal-native AI coding agent.

Work with codebases, files, repositories, and shell commands through a conversation-first interface.

```text
▌ CURSOR
offline · qwen2.5-coder:1.5b

> explain this project

cursor

This project is a terminal-native AI coding agent...
```

## Install

### npm

```bash
npm i -g @bniladridas/cursor
```

### Homebrew

```bash
brew tap palmshed/cursor
brew install palmshed/cursor/cursor
```

### Linux / macOS

```bash
curl -fsSL https://github.com/bniladridas/cursor/raw/main/install.sh | sudo sh
```
